# PR #74: GitHub button on the title page

**What changed**
- The title page has a **GitHub** button under *Start exploring*. It links to the project repository and opens in a
  new tab. It uses the GitHub mark as a line icon and the same pill style as the start button.
- With the GitHub button focused, Enter opens the link instead of starting the planner. Elsewhere on the title page,
  Enter and Escape still start the planner.

**Why**
Visitors to the public sites (Cloudflare Pages and sslip) had no way to find the source code.

**How to try it**
Open the planner. The title page shows the GitHub button. Click it, or Tab to it and press Enter, and the repository
opens in a new tab.

None: main through #72 (and the docs from #30) merged automatically.
