# PR #69: Fix the server running out of memory; plans never hang; plan errors in the AI chat

**What changed**
- **Memory** (`app.py`).
  - `Cube()` read each band with `z["bands"][i]`. That decompresses every band each time and keeps a full copy
    per band alive: Jezero took 370 MB instead of 18 MB, and an on-demand area about 200 MB, with up to 4 areas
    cached.
  - The 2 GB AWS server swapped 1.7 GB, so plans stalled and terrain tiles returned 503.
  - It now reads one array, 19 MB for Jezero.
  - Smaller in-memory tile caches: Viking 256 → 32 decoded tiles, Trek 5000 → 1500, CTX 3000 → 1000.
  - `deploy/aws/setup_server.sh` gives the service `MemoryHigh=1100M` and `MemoryMax=1500M`. If memory ever
    runs away again, the app restarts in seconds instead of swapping.
- **Plans never show "Planning…" forever.**
  - **Server stream:** the plan stream sends a keep-alive every 15 s and turns any unexpected failure into an
    `error` event. Before, the stream was just dropped.
  - **Area builds:** a stuck build is stopped after 5 min, or 15 min including minerals, and reported as failed.
  - **Page:** the planner gives up after 60 s of silence, or if the stream closes before `done`. Loading an area
    gives up after 6 min.
- **Errors in the AI chat.**
  - Failed plans are posted in the planner assistant, which opens with a **Try again** chip. That covers server
    errors, a lost connection, no landing spot (with its "go to the nearest firm ground" offer) and manual routes.
  - `maps_ui.js`: `chat.say(text, chips)`, and chips that run an action directly.
  - On pages without the chat, a notice on the map shows the error.
- `tests/test_planning_robust.py`.

**Why**
- **Planning hang:** planning sometimes showed "Planning…" forever after an error.
- **Memory:** the public AWS server was out of memory.

**How to try it**
Plan a mission. If the server fails or the connection drops, the chat says what happened within a minute and
offers Try again. On the AWS server, `systemctl show marswalk -p MemoryMax` shows the memory ceiling.
