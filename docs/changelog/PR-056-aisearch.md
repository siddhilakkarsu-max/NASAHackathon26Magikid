# PR #56: Fix floating terrain patches; deploy scripts for AWS Lightsail; Plan opens Results

**What changed**
- **3D terrain fix** (`murray.py`). About 1 in 6 tiles from Esri's global Mars elevation service (MDEM200M) at
  zoom levels 4, 5 and 7 hold heights from somewhere else, 1–7 km off. For example, at 7.5°N 5.6°W the service
  says +1,144 m, but NASA's MOLA map says −1,464 m. Patches of the globe floated above their neighbours with a
  hollow gap, and areas planned there got wrong elevations.
  - The server now checks every tile against NASA's MOLA elevation map (MEGDR, 16 px/degree, 33 MB, downloaded
    once into `cubes/murraycache/`).
  - A wrong tile is rebuilt from the nearest correct coarser tile, or from MOLA as a last resort.
  - Rebuilt tiles are written as LERC2 version 3, because Cesium's decoder can't read the v6 that the `lerc`
    package writes.
  - Tiles now load from `/murray/elevation/v2/`, so browsers drop the bad tiles they had cached; the old address
    still works.
  - Tests: `tests/test_elevation_check.py`.
- **AWS Lightsail hosting** (`deploy/aws/`).
  - A setup script and a deploy script.
  - Caddy provides HTTPS on a free sslip.io name.
  - The Claude key is kept on the server only.
  - Pending security updates are installed first.
  - See `deploy/aws/README.md`.
- **Hugging Face Space files** (`deploy/huggingface/`): a Docker Space. Unused, because Docker Spaces need HF PRO.
- **Left bar:** starting a plan from **Plan** moves the drawer to **Results**, where its progress and the AI's
  thinking appear.
  - This is one hook in `maps_ui.js`.
  - An older menu commit (d4c43dd) is in the history, but its code was replaced by Siddhi's version from #47.

**Why**
- The floating patches and hollow gaps were reported in the app.
- The team needed a cheap public server.

**How to try it**
- **Terrain:** choose **Topographic**, fly to 7.5°N 5.6°W or 24°N 15°W and tilt the view. The terrain is
  continuous, and clicking a spot shows about −1,400 m and about −1,800 m.
- **Old planning areas:** areas built before this fix on bad tiles (`cubes/site_*.npz`) still have the wrong
  heights. Delete them and they rebuild on demand.
