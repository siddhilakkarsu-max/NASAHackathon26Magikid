# PR #58: Electrolize font for all planner text, including the map labels

**What changed**
- The planner uses **Electrolize** (Google Fonts) for all its text: menus, buttons, labels, chips, the left bar,
  hover boxes, the landing page, and the titles ("MARS", the panel title, section headers, the tour card).
- **Form fields** (the search bar and the assistant's message box) also use it. Browsers give form fields their
  own default font unless they are told otherwise.
- **Map labels** (place and crater names, route numbers, pins, map notes, rover path ends) are painted onto the
  Cesium canvas, so CSS doesn't reach them. They now set Electrolize in their font strings through `mapFont(px)`.
  A label drawn before the web font has downloaded is redrawn once it has.
- **Other people's files:** text styled in other people's files (panel title, section headers and tour card in
  `maps_ui.css`; the mascot's speech in `mascot.css`; the Play button in `game-launch.js`) is overridden from
  `index.html`, so those files are unchanged.
- **Unchanged:** the "V" chevron on section headers keeps its old font, because it works as an arrow icon.

**Why**
Requested: one font across the planner, the map included.

**How to try it**
Open the planner and hard-refresh (Cmd+Shift+R). Turn on Place names and zoom in to see the map labels.

**Merge conflicts**
None: main through #57 merged automatically.
