# PR #59: Sharp map on high-DPI (Retina) screens

**What changed**
- The Cesium map draws at the screen's real pixel density (`useBrowserRecommendedResolution: false`), capped at
  2× so 3× phone screens stay smooth (`MAX_PIXEL_RATIO` in `index.html`).
- The globe's `maximumScreenSpaceError` is divided by the same ratio (1 → 0.5 on a 2× screen). Cesium measures
  tile detail in CSS pixels, so without this the terrain and photos would still load at half the detail the
  screen can show.
- The setting is applied again when the window moves to another screen or the page is zoomed.

**Why**
Cesium draws at CSS-pixel resolution by default and lets the browser stretch the picture, so on Retina screens
the map, its labels and its photos looked soft.

**Trade-off**
On a 2× screen the map draws about 4× as many pixels and loads more image tiles when zoomed in. That uses more
GPU and network, and adds some load on the CTX photo proxy. Lower `MAX_PIXEL_RATIO` if slower machines struggle.

**How to try it**
On a Retina screen, open the planner, choose the black-and-white photo map and zoom into Gale crater. Crater
rims and dune ridges are crisp. Before this change they were blurry.
